# PWA CS — CoupleSpace

Repositório do **CoupleSpace**, um PWA mobile-first para casais (chat, memórias, agenda e integração com Spotify).

## Estrutura do repositório

| Pasta | Conteúdo |
|-------|----------|
| `FRONTEND/` | Aplicação React + Vite (PWA) e o diretório `supabase/` com migrações e Edge Functions |
| `docs/` | Especificações, roadmap, guias de deploy e referências de UI |
| `fixs/` | Registros de correções e bugs resolvidos |
| `.planning/` | Planejamento do projeto (milestones, fases, requisitos) |

## Como rodar

Toda a aplicação vive em [`FRONTEND/`](./FRONTEND). Para rodar localmente:

```bash
cd FRONTEND
npm install
npm run dev
```

Consulte o [README do FRONTEND](./FRONTEND/README.md) para a stack completa, variáveis de ambiente e scripts.
