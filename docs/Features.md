# Features

## Objetivo

Desenvolver um Web App para casais, com foco em fortalecer a comunicação, registrar momentos especiais e compartilhar experiências de forma intuitiva. O projeto deve ser **mobile-first**, mantendo uma experiência consistente entre smartphones, tablets e desktop.

---

# Funcionalidades

## 💬 Chat

Área de conversa privada entre o casal.

### Requisitos

* Comunicação utilizando **pairID**.
* Envio de mensagens em tempo real.
* Gravação e envio de áudio utilizando recurso nativo do navegador.
* Envio de imagens.
* Responder (citar) mensagens.
* Reagir às mensagens com emojis.
* Interface otimizada para uso em dispositivos móveis.

---

## 🏠 Homepage

Tela principal com resumo da relação e conteúdos compartilhados.

### Componentes
* Título
* Destaque principal do dia + Foto escolhida pelo casal (upload próprio da galeria).
* Player de música integrado.
* Prévia da música atual do Spotify.
* Registro de humor (*Mood Tracker*):

  * Seleção rápida de humor através de reações pré-definidas.
  * Exemplos:


    * 😊 Feliz
    * 😴 Cansado
    * 😢 Triste
    * 😔 Com saudade
    * 🥺 Carente
* Card contendo:

  * Título
  * Descrição
* Mini álbum de fotos horizontal e arrastável (*drag/scroll*), localizado no final da página inicial.

---

## 📅 Agenda

Área destinada ao gerenciamento de compromissos do casal.

### Requisitos

* Cadastro de eventos.
* Integração com o Google Agenda.
* Visualização organizada por data.
* Possibilidade de criar lembretes para ambos os integrantes do casal.

---

# Regras do Projeto

## 1. Qualidade

* Não adicionar componentes incompletos ou quebrados.
* Toda funcionalidade deve estar implementada e navegável.

## 2. Responsividade

* Desenvolver utilizando abordagem **Mobile First**.
* Garantir adaptação para smartphones, tablets e desktop.

## 3. UI/UX

* Seguir integralmente a identidade visual definida para o projeto.
* Manter consistência de:

  * cores;
  * tipografia;
  * espaçamentos;
  * animações;
  * componentes;
  * ícones;
  * interações.

## 4. Experiência para Casais

Cada funcionalidade deve ser projetada considerando o uso simultâneo de duas pessoas conectadas através do **pairID**, promovendo interação, compartilhamento e colaboração.

## 5. Validação de Design

Antes da implementação completa:

1. Criar a primeira versão do layout.
2. Validar o design escolhido com o Dev.
3. Utilizar esse design como referência para todas as telas futuras.
4. Registrar, ao final deste arquivo (`features.md`), qual proposta visual foi aprovada para servir como padrão do projeto.

---

# Padrões Gerais

* Código limpo e organizado.
* Componentes reutilizáveis.
* Arquitetura escalável.
* Acessibilidade básica (contraste, navegação e foco).
* Performance otimizada.
* Animações suaves e discretas.
* Interface moderna, minimalista e romântica, sem excesso de elementos visuais.
