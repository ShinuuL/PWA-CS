# UI/UX

## Objetivo

Definir os padrões de interface e experiência do usuário para todo o projeto, garantindo consistência visual, usabilidade e adaptação para diferentes dispositivos.

---

# Referência Visual

O design deverá ser desenvolvido com base no arquivo *cosmic-v2.html*, que será anexado posteriormente.

Após sua validação, esse arquivo será considerado a **fonte oficial da identidade visual** do projeto e deverá servir como padrão para todas as implementações futuras.

**Observação:** O caminho ou referência do arquivo HTML deverá ser indexado ao final deste documento.

---

# Diretrizes de Interface

## 🎨 Identidade Visual

* Seguir integralmente o layout definido no HTML de referência.
* Manter consistência de:

  * Paleta de cores;
  * Tipografia;
  * Espaçamentos;
  * Bordas e sombras;
  * Ícones;
  * Animações;
  * Componentes visuais.

---

## 📱 Responsividade

* Desenvolver utilizando abordagem **Mobile First**.
* Garantir adaptação para:

  * Smartphones;
  * Tablets;
  * Desktop.

Nenhum componente deverá perder funcionalidade ou qualidade visual em diferentes resoluções.

---

## 🃏 Componentes em Cards

Sempre que fizer sentido para organização das informações, utilizar **Cards** como elemento principal da interface.

### Os cards devem possuir:

* Bordas arredondadas.
* Espaçamento interno consistente.
* Hierarquia visual clara.
* Sombras leves ou efeito de profundidade.
* Estados de interação (hover, active e focus quando aplicável).
* Animações suaves e discretas.

O objetivo é tornar a interface mais organizada, moderna e agradável para navegação.

---

# Experiência do Usuário (UX)

* Navegação intuitiva.
* Poucos cliques para concluir ações importantes.
* Feedback visual para todas as interações.
* Transições suaves entre páginas.
* Componentes reutilizáveis e padronizados.
* Priorizar simplicidade sem perder personalidade.

---

# Regras

## 1. Consistência

Toda nova tela deverá seguir exatamente o padrão visual definido neste documento e no HTML de referência.

## 2. Reutilização

Priorizar componentes reutilizáveis antes de criar novos elementos visuais.

## 3. Qualidade

Não implementar componentes incompletos, inconsistentes ou que destoem da identidade visual aprovada.

## 4. Evolução do Design

Caso o layout de referência seja atualizado, todas as novas implementações deverão utilizar a versão mais recente aprovada.
