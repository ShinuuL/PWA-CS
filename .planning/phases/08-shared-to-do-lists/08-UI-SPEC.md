## Spacing Scale

Declared values (multiples of 4, derived from existing codebase patterns):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip dot spacing, grid cell gaps |
| sm | 8px | Compact element padding, chip internal padding |
| md | 16px | Default element spacing, form input padding, modal padding |
| lg | 24px | Section padding, card internal padding, modal max-width gap |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0C14` (`--color-bg-dark`) | Page background |
| Secondary (30%) | `#12151F` (`--color-bg-card`) | Cards, modal backgrounds, list card grid |
| Accent (10%) | `#B87CFF` (`--color-primary`) | FAB, active tab, CTA buttons, progress indicators |
| Destructive | `#FF6B6B` | Delete confirmation button, overdue item date text |

Accent reserved for: FAB background, active SegmentedTab, "Criar lista"/"Criar item" CTA buttons, list card color accent line, completion progress text, assignee badge tint. NOT for list card backgrounds, not for item row backgrounds, not for general text.

- `#FFB87C` — warm (available for future use, not in this phase)

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 7 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | list-collection (no lists) | ✅ covered | Empty state with icon + "Nenhuma lista" heading + "Crie sua primeira lista compartilhada" body + "Criar lista" CTA button — follows RemindersTab pattern |
| empty | list-collection (no items in selected list) | ✅ covered | Empty state with "Nenhum item" heading + "Adicione o primeiro item a esta lista" body — distinct from no-lists state |
| loading | list-collection | ✅ covered | Skeleton rows (3x placeholder cards) with `agenda-pulse` animation — follows EventsTab skeleton pattern |
| loading | list items | ✅ covered | Skeleton rows (3x placeholder rows) with `agenda-pulse` animation — follows RemindersTab skeleton pattern |
| error | list-collection | ✅ covered | Error state with "Algo deu errado — Tente novamente" text + "Tentar novamente" retry button — follows RemindersTab error pattern |
| populated | list-card-grid | ✅ covered | 2-column grid of ListCards showing: color accent line (top), list name, item count (e.g., "3/5 concluidos"), completion progress. Cards use `--color-bg-card` background with `--radius-lg` corners |
| populated | item-rows | ✅ covered | Compact rows: checkbox | title (strikethrough if complete) | assignee badge (mini avatar) | due date (red if overdue). Completed items fade to opacity 0.6 and move to collapsible "Concluidos" section |
| overflow | item-list | ✅ covered | Scrollable container with `overflow-y: auto` on the items container. Completed section capped at `max-height: 400px` with overflow scroll — follows RemindersTab completed section pattern |
| zero-one-many | list-collection | ✅ covered | Zero: empty state (see above). One: single card in grid. Many: 2-column responsive grid with gap. Plural copy handled in count text (e.g., "3/5 concluidos") |
| long-text | list-name | 🧪 backstop | List name truncates with `text-overflow: ellipsis` + `white-space: nowrap` + `overflow: hidden` on the card title — verification via visual check that long names don't break card layout |
