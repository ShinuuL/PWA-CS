**Step 2: Create AvatarCropModal.jsx**
Create `FRONTEND/src/features/profile/AvatarCropModal.jsx` — a modal component that handles the full avatar upload flow: file selection → crop → compress → upload → profile update.

Component API: `<AvatarCropModal isOpen onClose onAvatarUpdated />`

Props:
- `isOpen` (boolean) — controls modal visibility
- `onClose` (function) — closes the modal
- `onAvatarUpdated` (function) — called with new avatar URL after successful upload

Internal state:
- `imgSrc` (string|null) — data URL of selected image
- `crop` (object) — current crop position
- `completedCrop` (object) — finalized crop coordinates
- `uploading` (boolean) — upload in progress
- `error` (string|null) — error message

Implementation per RESEARCH.md Pattern 1:
1. **File picker**: Hidden `<input type="file" accept="image/*">` triggered by an "Upload Photo" button (per Copywriting Contract). On file select:
   - Validate file type starts with `image/`
   - Reject files >15MB with error state (per D-28): "File too large. Maximum size is 15MB."
   - Read file as data URL via FileReader

2. **Crop tool**: Use `ReactCrop` from react-image-crop with:
   - `circularCrop` prop (per D-04 — strictly circular)
   - `aspect={1}` for square aspect ratio
   - `crop` and `onChange={setCrop}` for live crop state
   - `onComplete={setCompletedCrop}` for finalized coordinates
   - On image load: use `centerCrop(makeAspectCrop({ unit: '%', width: 90 }, 1, width, height), width, height)` to center the initial crop

3. **Compression** (per D-08, D-09): After user confirms crop, compress using Canvas API:
   - Create an `Image` element from `imgSrc`
   - Create a canvas, set dimensions to `completedCrop.width × completedCrop.height`
   - Use `ctx.drawImage(img, crop.x, crop.y, crop.width, crop.height, 0, 0, crop.width, crop.height)` to apply crop
   - Call `canvas.toBlob(resolve, 'image/jpeg', 0.8)` to produce ~200KB JPEG

4. **Upload**: Upload compressed blob to Supabase Storage:
   - Path: `${user.id}/avatar.${Date.now()}.jpg`
   - Use `supabase.storage.from('avatars').upload(filePath, blob, { upsert: true })`
   - On error: set error state, show toast with retry (per D-27): `toast.error('Upload failed. Tap to retry.', { ... })`
   - On success: get public URL, append `?v=${Date.now()}` for cache busting (per D-10, INFRA-06)
   - Update `profiles` table: `supabase.from('profiles').update({ avatar_url }).eq('id', user.id)`
   - Call `fetchProfile(user.id)` to refresh auth store
   - Show success toast (per Copywriting Contract): `toast.success('Profile photo updated')`
   - Call `onAvatarUpdated(avatarUrl)` and `onClose()`

5. **Upload state**: While uploading, show spinner overlay on avatar circle (per D-29). Use a simple CSS spinner animation.

6. **Modal layout**: Use `motion/react` AnimatePresence for modal transition. Background overlay with click-to-close. Modal content centered with crop tool, "Upload" CTA button, and "Cancel" button.

Import paths:
- `import ReactCrop, { centerCrop, makeAspectCrop } from 'react-image-crop'`
- `import 'react-image-crop/dist/ReactCrop.css'`
- `import { motion, AnimatePresence } from 'motion/react'`
- `import toast from 'react-hot-toast'`
- `import { supabase } from '../../shared/lib/supabase'`
- `import { useAuth } from '../auth/useAuth'`
