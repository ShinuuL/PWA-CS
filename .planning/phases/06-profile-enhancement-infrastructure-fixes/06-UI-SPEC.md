## Interaction Contracts

### Avatar Upload Flow (PROF-01, PROF-02, PROF-03)
1. User taps avatar circle on profile page → file picker opens (accept="image/*")
2. File >15MB rejected immediately with error text below avatar
3. File selected → modal opens with circular crop tool (react-image-crop, circularCrop, aspect=1)
4. User pinch-zooms and pans to position image behind fixed circular mask
5. User taps "Upload" → Canvas API compresses to ~200KB (quality=0.8, JPEG)
6. Spinner overlay on avatar circle during upload
7. Upload completes → profile URL updated with `?v=timestamp` cache bust
8. Success toast appears, avatar updates immediately everywhere (profile, header, drawer, chat)
9. Upload fails → toast with retry button

### Display Name Auto-Save (PROF-04)
1. User focuses name input → can type 1-30 characters
2. User blurs input → save triggers automatically
3. No explicit save button
4. Name updates in real-time across chat header and all past messages (D-20)

### Online Status Display (PROF-05, PROF-06, PROF-07)
1. Green dot (8px circle, #22C55E) appears next to partner avatar in chat header when online
2. Gray dot (8px circle, #8B8FA3) appears when partner is offline
3. "last seen X ago" text appears below partner name ONLY if offline >1 hour (D-07)
4. Relative time uses date-fns formatDistanceToNow (D-06)
5. Status updates via Supabase Realtime Presence — no polling

### Partner Profile Modal (D-23 through D-26)
1. Tap partner avatar in chat header OR partner profile button in drawer → modal opens
2. Modal is bottom-sheet style (slides up from bottom), not full page
3. Shows: partner avatar (96px circle) + display name + online status dot
4. "Message" button at bottom → navigates to chat and closes modal
5. View only — no edit capabilities
6. Close on overlay tap or swipe down
