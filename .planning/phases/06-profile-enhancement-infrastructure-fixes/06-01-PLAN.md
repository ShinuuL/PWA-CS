  <action>
Create `FRONTEND/src/hooks/usePresence.js` — a custom React hook that wraps Supabase Realtime Presence to track partner online status (PROF-07, per D-13).

The hook signature: `usePresence(pairId, userId)` returns `{ isOnline, lastSeen }`.

Implementation per the RESEARCH.md Pattern 2:
1. Accept `pairId` (the pair ID) and `userId` (the partner's user ID — the one whose status we're tracking)
2. Create a Supabase channel named `pair:${pairId}` with presence config keying on `userId`
3. Subscribe to presence events:
   - `sync`: Check if the tracked user is in the presence state. If yes, set `isOnline = true` and update `lastSeen` to their `online_at` timestamp
   - `leave`: Set `isOnline = false` and capture `lastSeen` from the leaving presence
4. On channel subscription status `SUBSCRIBED`, call `channel.track({ online_at: new Date().toISOString() })` to register THIS user's presence
5. Return cleanup function that calls `supabase.removeChannel(channel)` (critical to prevent memory leaks per Pitfall 3)
6. Only subscribe if both `pairId` and `userId` are truthy

Important details:
- Import `supabase` from `../shared/lib/supabase`
- Use `useState` for `isOnline` (default `false`) and `lastSeen` (default `null`)
- Use `useEffect` with `[pairId, userId]` dependencies
- The hook tracks the CURRENT user's presence and exposes the partner's status via the presence state
- Format: `{ online_at: ISO timestamp }` in track payload
