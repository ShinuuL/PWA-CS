### Typography Rules

- Message text: 16px / weight 400 / line-height 1.5 (D-13)
- Timestamps: 14px / weight 400 / line-height 1.4 (D-13)
- Timestamps use `--chat-timestamp` color (#5E5B75)
- Date separators: 12px / weight 600 / uppercase / letter-spacing 1px / centered with horizontal line
- Quote preview text: 14px / weight 400 / line-height 1.4 / max 3 lines with ellipsis (D-16)
- Deleted message placeholder: 14px / weight 400 / italic / `--chat-deleted-text` color

## Layout Contract

### Chat Screen Layout

```
┌─────────────────────────────────┐
│  ChatHeader (56px, fixed)       │  ← partner avatar + name + back + settings
├─────────────────────────────────┤
│                                 │
│  MessageList (flex: 1, scroll)  │  ← messages area, scrollable
│                                 │
│  [DateSeparator]                │
│  [MessageBubble - received]     │
│  [MessageBubble - received]     │  ← grouped if consecutive same sender
│  [TimeDivider]                  │
│  [MessageBubble - sent]         │
│  [ReactionChip row]             │  ← below bubble
│  ...                            │
│                                 │
│  [NewMessagesButton]            │  ← floating, shown when scrolled up
│                                 │
├─────────────────────────────────┤
│  MessageInput (fixed, bottom)   │  ← text field + send button, always visible
└─────────────────────────────────┘
```

### Message Bubble Layout

```
┌──────────────────────────────┐
│ [QuotePreview]               │  ← optional: left border, 2-3 lines max (D-16, D-17)
│ ┌────────────────────────┐   │
│ │ Original message text  │   │
│ │ with ellipsis if long  │   │
│ └────────────────────────┘   │
│                              │
│ Message text content here    │  ← 16px body text (D-13)
│                              │
│ 14:25  ✓✓                   │  ← timestamp + delivery indicator
└──────────────────────────────┘
  [❤️ 3] [😂 1]                │  ← reaction chips below bubble (D-20, D-22)
```

### Message Grouping Rules (D-06)

- Consecutive messages from same sender: no timestamp between them, no avatar重复
- Time gap > 5 minutes: show `TimeDivider` with timestamp
- New day: show `DateSeparator` (centered line + date text)

### Auto-Scroll Rules (D-11)

- If user is at bottom (within 100px): auto-scroll to new message
- If user has scrolled up: show "New messages" floating button
- Clicking "New messages" scrolls to bottom smoothly

## Interaction Contract

### Long-Press (Mobile) — D-15, D-18, D-31

- **Trigger:** Long-press (500ms hold) on any message bubble
- **Behavior:** Show context menu with Reply and Delete options
- **Haptic:** Device vibration on long-press trigger (if supported)
- **Position:** Context menu appears above the pressed message, centered horizontally
- **Dismiss:** Tap outside menu to dismiss
- **Minimum touch target:** 44px for all menu items (CHAT-07)

### Swipe to Reply (Mobile) — D-15

- **Trigger:** Swipe right on message bubble (minimum 80px displacement)
- **Behavior:** Opens reply composer mode (quote preview in input area)
- **Animation:** Message slides right, reply indicator slides in from left
- **Cancel:** Release before threshold snaps back

### Reaction Picker — D-18, D-19

- **Trigger:** Long-press on message bubble (same as context menu)
- **Behavior:** Show reaction picker overlay with 8 emojis
- **Emojis:** ❤️ 😂 👍 👎 😢 🔥 😍 🎉 (D-19)
- **Layout:** Horizontal row, centered above message
- **Selection:** Tap emoji to add reaction, tap again to remove own reaction
- **Animation:** Pop-in with scale animation (D-21) — scale from 0.5 to 1.0, opacity 0 to 1, duration 200ms

### Reaction Chips — D-20, D-22

- **Position:** Below message bubble, right-aligned for sent, left-aligned for received
- **Layout:** Horizontal flex, gap 4px
- **Chip:** Rounded pill, background `--chat-reaction-bg`, border `--chat-reaction-border`
- **Content:** Emoji + count (e.g., "❤️ 3")
- **Own reaction highlight:** If current user reacted, border becomes `--color-primary` with slightly brighter background
- **Animation:** Scale from 0 to 1 with spring physics (D-21)

### Message Input — D-08

- **Position:** Fixed at bottom of chat view
- **Layout:** Horizontal — text input (flex: 1) + send button (44px circle)
- **Input:** Rounded, background `--chat-input-bg`, 16px text, placeholder "Type a message..."
- **Send button:** Circular, 44px, background `--color-primary` when text present, muted when empty
- **Keyboard:** Input pushes chat area up, chat scrolls to bottom
- **Reply mode:** When replying, show quote preview above input with X to cancel

### Context Menu — D-31

- **Position:** Appears above the pressed message
- **Background:** `--color-bg-card` with subtle shadow
- **Border:** 1px solid `--color-border`, border-radius 12px
- **Items:** Reply (icon + text), Delete (icon + text, red)
- **Height:** Each item minimum 44px touch target

### Delivery Indicators — D-03

- **Sent:** Single check mark, color `--color-text-secondary`
- **Read:** Double check mark, color `--color-primary`
- **Position:** Bottom-right of sent message bubble, inline with timestamp

### Typing Indicator — D-04

- **Trigger:** Partner starts typing (detected via Supabase Realtime)
- **Display:** Three animated dots in a small bubble, left-aligned
- **Animation:** Sequential dot bounce (scale 1.0 → 1.3 → 1.0, staggered 150ms)
- **Dismiss:** Hidden 3 seconds after partner stops typing

### New Messages Button — D-11

- **Position:** Fixed, bottom-center, above input area (bottom: 80px)
- **Style:** Rounded pill, background `--color-primary`, white text, shadow
- **Content:** "↓ New messages"
- **Animation:** Slide up when visible, slide down when hidden
- **Click:** Smooth scroll to bottom of message list

## Animation Contract

All animations use the `motion` library (framer-motion v12.42).

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| MessageBubble (new) | Slide up from bottom + fade in | 200ms | ease-out |
| ReactionChip (added) | Scale pop-in 0.5→1.0 + fade in | 200ms | spring (stiffness 300, damping 20) |
| ReactionChip (removed) | Scale down 1.0→0.5 + fade out | 150ms | ease-in |
| ReactionPicker | Scale from 0.8→1.0 + fade in, origin: bottom-center | 200ms | spring (stiffness 400, damping 25) |
| ContextMenu | Fade in + translateY(-4px→0) | 150ms | ease-out |
| DeleteConfirmDialog | Backdrop fade in + modal scale 0.95→1.0 | 200ms | ease-out |
| NewMessagesButton | translateY(20px→0) + fade in | 200ms | ease-out |
| TypingIndicator dots | Sequential bounce (staggered 150ms per dot) | 600ms loop | ease-in-out |
| Swipe to Reply | translateX(0→80px) on drag, spring back on release | spring | stiffness 300, damping 30 |
| DateSeparator | Fade in | 300ms | ease-in |
| DeliveryIndicator (checkmarks) | Fade in | 200ms | ease-out |
