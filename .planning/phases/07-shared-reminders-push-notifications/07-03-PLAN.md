## Objective

Build the complete RemindersTab UI — list view with grouped reminders, creation form with DateTimePicker, reminder cards with creator attribution and swipe-to-dismiss, and collapsible completed section.

Purpose: Core user-facing feature — couples create, view, and dismiss reminders through a polished mobile-first interface.

Output: RemindersTab, ReminderCard, ReminderForm components with co-located CSS. Fully integrated into AgendaPage.

  **ReminderCard.jsx** — Displays a single reminder:
  - Props: `{ reminder, onComplete, onEdit }`
  - Layout (per D-11): Left section shows formatted date/time (day number + abbreviated month from `reminder_at`), middle section shows title + time, right section shows creator avatar + name
  - Creator attribution (REMN-03, D-11): Fetch `profiles` join on `created_by` from Supabase (or receive as prop from parent). Show avatar (circular, 32px) and display_name. If avatar_url null, show initials.

  - Swipe-to-dismiss (D-13): Use `motion` (framer-motion) `drag="x"` with `dragConstraints={{ left: -100, right: 0 }}`. On swipe left past threshold (-80px), trigger `onComplete`. Visual feedback: card slides left, fades, green checkmark appears during swipe. Use `AnimatePresence` for exit animation.
  - Touch: `onTouchStart` / `onTouchEnd` handlers for swipe detection. `touchAction: 'pan-y'` to allow vertical scroll while horizontal swipe works.
  - CSS (`ReminderCard.css`): Match EventRow style — flex row, 12px gap, border-bottom. Avatar circular with `border-radius: 50%`. Priority dot: 8px circle, absolute positioned. Swipe background: green overlay with checkmark icon that appears during drag.

  **ReminderForm.jsx** — Modal form for creating/editing reminders:
  - Props: `{ onSubmit, onCancel, initialReminder? }`
  - Fields (per D-10):
    1. Title (required) — text input, placeholder "Título do lembrete"
    2. Date/Time (required) — DateTimePicker component (from Plan 02). Button shows formatted current selection, tapping opens DateTimePicker modal
    3. Notes (optional) — textarea, placeholder "Notas (opcional)"
    4. Priority — select: "Baixa" (low), "Normal" (normal), "Alta" (high)
    5. Category — select: "Geral", "Trabalho", "Pessoal", "Saúde", "Outro"
  - Submit button: "Criar lembrete" (create mode) or "Salvar" (edit mode)
  - Cancel button: "Cancelar"
  - Form validation: title must not be empty, date/time must be set
  - On submit: call `onSubmit({ title, reminder_at: combinedDate, notes, priority, category })`
  - Follow EventForm pattern exactly: input/textarea/select styling, action buttons layout
  - CSS (`ReminderForm.css`): Follow EventForm CSS pattern — same input styles, same button styles, same gap/spacing. DateTimePicker trigger styled as a button showing current formatted date/time.

- **Action:**

  **RemindersTab.jsx** — Full implementation:

  1. **Loading state**: Same skeleton pattern as EventsTab — 3 skeleton cards
  2. **Error state**: Same pattern — "Algo deu errado" message + retry button
  3. **Empty state** (per D-03): Illustration (reuse existing SVG or emoji + styled container), "Nenhum lembrete" title, "Criar lembrete" CTA button. Match EventsTab empty state styling.
  4. **List view** (per D-11, D-12):
     - Split reminders into two groups: upcoming (completed_at IS NULL, reminder_at >= now) and completed (completed_at IS NOT NULL OR status = 'sent')
     - Upcoming reminders: Group by date (same pattern as EventsTab groupedEvents with `format(new Date(reminder_at), 'yyyy-MM-dd')`), sort ascending
     - Display each group with date header (formatted as "d 'de' MMMM" in ptBR locale)
     - Each reminder renders ReminderCard
     - Completed reminders: Collapsible "Concluídos" section at bottom (per D-12). Show count badge when collapsed ("3"). Toggle expand/collapse. When expanded, show completed ReminderCards with reduced opacity.
  5. **FAB** (per EventsTab pattern): Fixed bottom-right Plus button. On click, open modal with ReminderForm.
  6. **Create modal**: Same pattern as EventsTab — overlay with modal container, "Criar lembrete" title, ReminderForm inside. On submit, call `reminderStore.createReminder()`, show toast on success/error, close modal.
  7. **Edit modal**: When ReminderCard's edit action triggered, open same modal with `initialReminder` prop pre-filled. On submit, call `reminderStore.updateReminder()`.
  8. **Push permission request** (per D-09): On first reminder creation success, check `Notification.permission`. If 'default', show a small toast: "Ative notificações para receber lembretes" with a button that calls `Notification.requestPermission()`. Don't block the creation flow.

  - `.reminders-tab__list` flex column, gap 1rem
  - `.reminders-tab__group` background card, rounded, padding 0.75rem
  - `.reminders-tab__group-date` same as `.events-tab__group-date`
  - `.reminders-tab__empty` same as `.events-tab__empty`
  - `.reminders-tab__fab` same as `.events-tab__fab`
  - `.reminders-tab__modal-overlay` same as `.events-tab__modal-overlay`
  - `.reminders-tab__modal` same as `.events-tab__modal`
  - `.reminders-tab__completed-section` collapsible section with toggle header
  - `.reminders-tab__completed-header` flex row, justify between, padding, cursor pointer
  - `.reminders-tab__completed-badge` small pill, background primary-light, count number
  - `.reminders-tab__completed-list` max-height with overflow, transition for collapse animation
