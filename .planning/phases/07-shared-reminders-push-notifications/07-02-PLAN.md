## Objective

Build the reusable DateTimePicker component (calendar + scroll-wheel time picker) used by ReminderForm and later Phase 8 (Shared To-Do Lists due dates).

Purpose: Core UX component — couples set date/time for reminders via a polished, touch-friendly picker. Reusable by Phase 8.

Output: DateTimePicker.jsx, TimePicker.jsx with co-located CSS.

## Tasks

### Task 1: Build TimePicker with Scroll Wheel (hours + minutes)
- **Type:** feature
- **Files:** FRONTEND/src/features/agenda/TimePicker.jsx, FRONTEND/src/features/agenda/TimePicker.css
- **read_first:**
  - FRONTEND/src/features/agenda/CalendarGrid.jsx (component structure, motion import pattern, `motion/react` import)
  - FRONTEND/package.json (check if `@ncdai/react-wheel-picker` is installed; if not, implement custom scroll wheel per research Option 2)
- **Action:** Create a `TimePicker` component with two scroll columns for hours (00-23) and minutes (00-59):

  If `@ncdai/react-wheel-picker` is installed in package.json:
  - Use `WheelPicker` and `WheelPickerWrapper` from the library
  - Generate hour items: `Array.from({ length: 24 }, (_, i) => ({ value: String(i).padStart(2, '0'), label: String(i).padStart(2, '0') }))`
  - Generate minute items: `Array.from({ length: 60 }, (_, i) => ({ value: String(i).padStart(2, '0'), label: String(i).padStart(2, '0') }))`
  - Props: `{ value: { hour: '09', minute: '00' }, onChange: (newValue) => void }`
  - Wrap in `WheelPickerWrapper` with two `WheelPicker` children

  If `@ncdai/react-wheel-picker` is NOT installed (build custom per research Option 2):
  - Two columns, each a vertically scrollable container
  - Each column shows ~5 visible items, center item highlighted
  - CSS `scroll-snap-type: y mandatory` for snap behavior
  - `itemHeight = 40px`, container height = `itemHeight * 5 = 200px`
  - Touch-friendly: min 44px touch targets, smooth scroll on drag
  - Props same as above
  - Use `motion` (framer-motion) for smooth scroll animations

  Props interface (both implementations):
  ```
  { value: { hour: string, minute: string }, onChange: ({ hour, minute }) => void }
  ```

  CSS (`TimePicker.css`):
  - `.time-picker` flex row, gap between columns
  - `.time-picker__column` centered label above, scroll container below
  - `.time-picker__column-label` font-size 0.75rem, uppercase, color secondary
  - `.time-picker__items` overflow hidden, height ~200px, scroll snap
  - `.time-picker__item` height 40px, center item highlighted with primary color
  - Dark theme compatible using CSS custom properties (`--color-bg-card`, `--color-text-primary`, `--color-text-secondary`, `--color-primary`)
- **Verify:**
  ```bash
  cd FRONTEND && npm run lint
  ```
  Manual: Render TimePicker with initial value `{ hour: '14', minute: '30' }`. Verify both columns display. Scroll/tap to change values. Verify onChange fires with new value.
- **Acceptance Criteria:**
  - [ ] TimePicker.jsx renders two columns: hours (00-23) and minutes (00-59)
  - [ ] TimePicker accepts `value` prop with `{ hour, minute }` shape
  - [ ] TimePicker calls `onChange` when user selects new hour or minute
  - [ ] Scroll snap or wheel picker provides smooth, touch-friendly interaction
  - [ ] Center item (selected) visually highlighted with primary color
  - [ ] CSS uses project custom properties for theming

### Task 2: Build DateTimePicker Combining CalendarGrid + TimePicker
- **Type:** feature
- **Files:** FRONTEND/src/features/agenda/DateTimePicker.jsx, FRONTEND/src/features/agenda/DateTimePicker.css
- **read_first:**
  - FRONTEND/src/features/agenda/CalendarGrid.jsx (props interface: `currentMonth`, `onMonthChange`, `onDayClick`, `events` — we reuse without events for date-only selection)
  - FRONTEND/src/features/agenda/TimePicker.jsx (from Task 1 — import and use)
  - FRONTEND/src/features/agenda/EventForm.jsx (action button pattern: "Cancelar" / "Confirmar" at bottom)
- **Action:** Create `DateTimePicker` component:

  Props:
  ```
  {
    value: Date | null,           // current selected datetime
    onChange: (date: Date) => void, // called when user confirms
    onCancel: () => void,         // called when user cancels
    minDate?: Date                // optional minimum date (default: now)
  }
  ```

  Internal state:
  - `selectedDate` — initialized from `value` prop or `new Date()`
  - `selectedTime` — `{ hour: '09', minute: '00' }` or derived from `value` prop

  Structure (top to bottom):
  1. CalendarGrid — reuse existing component. Pass `currentMonth={selectedDate}`, `onMonthChange={setSelectedDate}`, `onDayClick={(day) => setSelectedDate(day)}`. No events prop needed.
  2. TimePicker — from Task 1. Pass `value={selectedTime}` and `onChange={setSelectedTime}`.
  3. Action buttons — "Cancelar" (calls `onCancel`) and "Confirmar" (combines date + time into a single Date, calls `onChange`). Follow EventForm button styling pattern.

  When "Confirmar" is clicked:
  - Create new Date from selectedDate
  - Set hours from selectedTime.hour, minutes from selectedTime.minute
  - If minDate provided and result is before minDate, show toast error "Selecione uma data no futuro"
  - Call onChange with the combined Date

  CSS (`DateTimePicker.css`):
  - `.datetime-picker` column layout, gap between sections
  - `.datetime-picker__section` background card, rounded, padding
  - `.datetime-picker__section-label` uppercase, small, secondary color
  - `.datetime-picker__actions` flex row, gap, same as EventForm actions pattern
  - `.datetime-picker__btn` / `.datetime-picker__btn--cancel` / `.datetime-picker__btn--submit` matching EventForm button styles
- **Verify:**
  ```bash
  cd FRONTEND && npm run lint
  ```
  Manual: Render DateTimePicker. Select a date on calendar grid. Scroll to select time. Tap Confirmar — verify onChange fires with correct combined Date. Tap Cancelar — verify onCancel fires. Verify minDate prevents past dates.
- **Acceptance Criteria:**
  - [ ] DateTimePicker renders CalendarGrid + TimePicker + action buttons
  - [ ] CalendarGrid displays current month with day selection
  - [ ] TimePicker displays hour and minute scroll columns
  - [ ] Confirmar button combines date + time into single Date object
  - [ ] Cancelar button calls onCancel
  - [ ] minDate prop prevents selecting past dates (shows toast)
  - [ ] Component is reusable — no hard-coded reminder-specific logic
  - [ ] CSS uses project custom properties, dark theme compatible
  - [ ] `npm run lint` passes
