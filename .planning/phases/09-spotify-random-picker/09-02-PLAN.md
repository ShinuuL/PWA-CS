      3. Build Set of recently played track URIs
      4. Filter: candidates = playlistTracks.filter(t => !recentUris.has(t.uri))
      5. If candidates is empty: candidates = playlistTracks (full cycle reset)
      6. Pick random: candidates[Math.floor(Math.random() * candidates.length)]
      7. Start playback via Web Playback SDK (transfer to device_id)
      8. Insert into spotify_play_history (pair_id, track_uri, track_name, track_artist)
      9. Periodically clean up entries older than 7 days
    - stopAutoRotate(): clearInterval
    - Pause when document.visibilitychange = 'hidden', resume when visible
    - Timer reference stored in state (autoRotateTimer)
  </behavior>

       - const { playlistTracks, deviceId, pairId } = get()
       - if (!playlistTracks.length || !deviceId) return
       - Query: supabase.from('spotify_play_history').select('track_uri').eq('pair_id', pairId).order('played_at', { ascending: false }).limit(50)
       - Build Set from result
       - Filter playlistTracks
       - Pick random from candidates
       - Call Spotify API: PUT /v1/me/player/play with { device_ids: [deviceId], uris: [track.uri] }
