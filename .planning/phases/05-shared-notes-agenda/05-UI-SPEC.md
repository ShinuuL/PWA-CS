## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (0.25rem) | Icon gaps, inline padding, album grid gap |
| sm | 8px (0.5rem) | Compact element spacing, form field gaps |
| md | 16px (1rem) | Default element spacing, card padding, section gaps |
| lg | 24px (1.5rem) | Section padding, modal padding |
| xl | 32px (2rem) | Layout gaps, major section breaks |
| 2xl | 48px (3rem) | Empty state padding |

**Exceptions:** Event row gap is 14px (from `cosmic-v2.html` line 521: `gap: 14px`) — not a multiple of 4, inherited from design reference. Category pill padding is 4px 10px (from `cosmic-v2.html` line 556: `padding: 4px 10px`).

**Source:** Extracted from existing CSS across `dashboard.css`, `album.css`, `index.css`, and `cosmic-v2.html`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0C14` (`--color-bg-dark`) | Page background, app shell background |
| Secondary (30%) | `#12151F` (`--color-bg-card`) | Cards, calendar grid container, note cards, event rows background |
| Accent (10%) | `#B87CFF` (`--color-primary`) | Active tab background, CTA buttons, focus borders, calendar today highlight, category pills, "see all" links |
| Destructive | `#FF6B6B` | Delete note/event buttons, destructive confirmation actions |

**Accent reserved for:**
1. Active segmented tab (filled pill background)
2. Primary CTA buttons ("Criar nota", "Criar evento")
3. Focus border on form inputs (title, description, date picker)
4. Calendar grid: today's cell highlight
5. Category pill background (`--primary-glow` equivalent, tinted)
6. "Ver todas as notas" / "Ver todos os eventos" link text

**Additional tokens from `index.css`:**
- `--color-bg-input: #1A1E2E` — form input backgrounds, inactive tab backgrounds
- `--color-text-primary: #FFFFFF` — all primary text
- `--color-text-secondary: #8B8FA3` — descriptions, labels, placeholder text, empty state text
- `--color-border: #2A2E3F` — input borders, dividers, dashed empty state borders
- `--radius-md: 12px` — buttons, inputs, cards, pills
- `--radius-lg: 16px` — modals, large cards

**Source:** `index.css` lines 1-11, `cosmic-v2.html` lines 555-564, existing feature CSS patterns.
