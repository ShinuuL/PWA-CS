## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client to Supabase moods table | Mood writes via upsert cross this boundary -- RLS enforces user ownership and pair membership |
| Supabase Realtime to client | Partner mood updates push via websocket -- subscription scoped to pair_id filter |
| client to Supabase RPC | MemoryHero reads random photo via RPC -- RLS on album_photos ensures pair-scoped access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
