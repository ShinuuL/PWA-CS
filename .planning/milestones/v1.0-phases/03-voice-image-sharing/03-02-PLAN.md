**Step 1: Supabase Migration — Create album_photos table**

Apply via Supabase MCP `apply_migration` or SQL editor:

```sql
CREATE TABLE IF NOT EXISTS album_photos (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  pair_id UUID NOT NULL REFERENCES pairs(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  url TEXT NOT NULL,
  storage_path TEXT NOT NULL,
  caption TEXT DEFAULT '',
  width INTEGER,
  height INTEGER,
  file_size INTEGER,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- RLS policies
ALTER TABLE album_photos ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Pair members can view album photos"
ON album_photos FOR SELECT TO authenticated
USING (
  pair_id IN (
    SELECT id FROM pairs WHERE user_one = auth.uid() OR user_two = auth.uid()
  )
);

CREATE POLICY "Pair members can insert album photos"
ON album_photos FOR INSERT TO authenticated
WITH CHECK (
  pair_id IN (
    SELECT id FROM pairs WHERE user_one = auth.uid() OR user_two = auth.uid()
  )
  AND user_id = auth.uid()
);

CREATE POLICY "Pair members can delete their own album photos"
ON album_photos FOR DELETE TO authenticated
USING (
  user_id = auth.uid()
  AND pair_id IN (
    SELECT id FROM pairs WHERE user_one = auth.uid() OR user_two = auth.uid()
  )
);

-- Index for chronological ordering
CREATE INDEX IF NOT EXISTS idx_album_photos_pair_created ON album_photos (pair_id, created_at DESC);
```

RLS policies for album-photos bucket:
```sql
CREATE POLICY "Pair members can upload album photos"
ON storage.objects FOR INSERT TO authenticated
WITH CHECK (
  bucket_id = 'album-photos'
  AND (storage.foldername(name))[1] IN (
    SELECT pair_id::text FROM pairs WHERE user_one = auth.uid() OR user_two = auth.uid()
  )
);

CREATE POLICY "Pair members can read album photos"
ON storage.objects FOR SELECT TO authenticated
USING (
  bucket_id = 'album-photos'
  AND (storage.foldername(name))[1] IN (
    SELECT pair_id::text FROM pairs WHERE user_one = auth.uid() OR user_two = auth.uid()
  )
);

CREATE POLICY "Pair members can delete their album photos"
ON storage.objects FOR DELETE TO authenticated
USING (
  bucket_id = 'album-photos'
  AND (storage.foldername(name))[1] IN (
    SELECT pair_id::text FROM pairs WHERE user_one = auth.uid() OR user_two = auth.uid()
  )
);
```

**Step 3: Create albumStore.js**

Create `FRONTEND/src/stores/albumStore.js` as a Zustand store following the same patterns as chatStore.js:

State:
- `photos: []` — array of album photo records, ordered by created_at DESC
- `loading: boolean` — true while fetching photos
- `uploading: boolean` — true while an upload is in progress
- `error: string | null` — error message
- `pairId: string | null` — current pair ID

Actions:
- `initializeAlbum(pairId)`: Fetch all album_photos for this pair, ordered by created_at DESC. Set photos state. Subscribe to real-time changes on album_photos table (INSERT/DELETE) filtered by pair_id, same pattern as chatStore's subscription.
- `uploadAlbumPhoto(file, caption)`: (1) Call `compressImage(file)` from shared/lib/imageCompress.js (per D-10). (2) Upload compressed blob to Supabase Storage 'album-photos' at path `{pairId}/{timestamp}-{random}.jpg`. (3) Get public URL. (4) Insert record into album_photos table with pair_id, user_id, url, storage_path, caption, width, height, file_size. (5) Optimistically add the photo to the photos array immediately with a local blob URL, then replace with real URL after insert. (6) Set uploading state during process.
- `deletePhoto(photoId, storagePath)`: Delete from album_photos table AND from Supabase Storage. Remove from local state.
- `cleanup()`: Remove real-time subscription, reset state.

The real-time subscription should handle INSERT (add photo to state if not already there from optimistic update) and DELETE (remove photo from state).
