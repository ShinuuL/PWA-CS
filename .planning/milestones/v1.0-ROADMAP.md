# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-07-25
**Phases:** 1-3
**Total Plans:** 8

## Overview

v1.0 MVP delivers the core CoupleSpace experience: authentication, couple pairing, real-time private chat with rich interactions (replies, reactions, delete, typing indicators), voice messages, image sharing, and a shared photo album.

## Phases

### Phase 1: Foundation & Pairing

**Goal**: Two users can authenticate, pair, and see each other's profiles in a shared private space
**Depends on**: Nothing (first phase)
**Plans**: 3 plans

Plans:

- [x] 01-01: Project Scaffold & Supabase Foundation (Vite + PWA, Supabase client, DB schema, auth store, app shell)
- [x] 01-02: Authentication & Pairing System (Google OAuth, auth callback, invite codes, pairing UI, session persistence)
- [x] 01-03: Profile Management & App Shell (profile edit, avatar upload, partner view, drawer navigation, settings)

### Phase 2: Real-Time Chat

**Goal**: Paired couples can exchange real-time messages with rich interaction
**Depends on**: Phase 1
**Plans**: 3 plans

Plans:

- [x] 02-01: Chat Schema + Core Real-time Messaging — Database migration, Zustand chat store with Supabase Realtime, core ChatView
- [x] 02-02: Replies + Reactions + Delete + Typing — QuotePreview, reply mode, ContextMenu, DeleteConfirmDialog, ReactionPicker, TypingIndicator
- [x] 02-03: Chat Settings + Notifications + Mobile Polish — Chat settings page, push notifications, mobile touch target audit

### Phase 3: Voice & Image Sharing

**Goal**: Couples can exchange voice messages and images within their chat, and build a shared photo album
**Depends on**: Phase 2
**Plans**: 2 plans

Plans:

- [x] 03-01: Voice Messages + Image Sharing in Chat — DB migration, storage bucket, voice recording, image compression, inline media components
- [x] 03-02: Shared Photo Album — album_photos table, album-photos bucket, albumStore, AlbumPage with upload/grid, MiniAlbum on homepage

## Milestone Summary

**Key Decisions:**

- Replaced `react-audio-visualize` with custom Canvas Waveform.jsx (React 19 incompatibility)
- Optimistic messages tracked via `pendingTempIds` for reliable realtime replacement
- Supabase-first architecture: all CRUD through client SDK, FastAPI only for external API proxying
- PairID as universal access key: every table gets pair_id column with RLS

**Issues Resolved:**

- React 19 incompatibility with react-audio-visualize library
- Optimistic message replacement bug (temp_id not in Supabase realtime payload)
- Storage RLS policy SQL bugs (pair_id → id in bucket policies)
- Infinite re-render loop in usePairing (missing useCallback memoization)

**Technical Debt:**

- `gh` CLI not installed — PR creation via manual link
- Some migrations applied manually via SQL Editor (MCP timeouts)
- ServiceWorker MIME type warning in dev (non-blocking)
