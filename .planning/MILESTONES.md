# Milestones

## v1.0 MVP

**Shipped:** 2026-07-25
**Phases:** 1-3 (8 plans)
**Requirements:** 19/27 v1 requirements complete

### Accomplishments

1. Google OAuth authentication with session persistence
2. Couple pairing via invite code/link system with profile management
3. Real-time private chat with Supabase Realtime (text, replies, reactions, delete, typing indicators)
4. WhatsApp-style voice messages with hold-to-record and live waveform
5. Image sharing in chat with compression and fullscreen viewer
6. Shared photo album with grid view, upload, and navigation
